# 🎓 SPCU-CIICP — Syllabus Discussion Platform

### 📚 Collaborative Learning | PSG Polytechnic College

**SPCU (CIICP)** is a syllabus discussion platform developed for PSG Polytechnic College under the **Canada–India Institutional Co-Operation Project**. The project provides a dedicated online platform to support syllabus-related discussions and academic collaboration.

## ✨ Project Highlights

- 🎓 **Academic Collaboration** — Supports syllabus-related discussions.
- 🏫 **College Project** — Developed for PSG Polytechnic College.
- 🌐 **Web-Based Platform** — Accessible through the college's official website.
- 📚 **Syllabus Discussion** — Focuses on academic information and collaborative learning.
- 💻 **Web Development** — Demonstrates practical website development experience.

## 🔗 Live Website

👉 **[Visit the SPCU-CIICP Portal](https://psgpolytech.ac.in/SPCU/)**

## 🎯 Project Objective

To provide a dedicated online platform for syllabus discussions and support academic collaboration within the college community.
